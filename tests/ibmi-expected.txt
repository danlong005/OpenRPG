# Whether each test program should compile with IBM's ILE RPG compiler on a
# real IBM i — the "Should compile" column of the wiki page
# IBM-i-Conformance-Results (scripts/conformance-wiki.py).
#
# The default needs no entry here: a test registered in tests/run_tests.sh in
# "error" mode is written to be rejected, so IBM should reject it too; every
# other program should compile. This file lists only the exceptions, each with
# the reason it is one.
#
# Format:  <file>  compile|reject  <reason>

# rpgc refuses these on purpose — they are registered as error tests — but they
# are valid RPG, and IBM compiles them.

test213_fixed_cspec_err_move_jobrun.rpgle   compile  valid RPG; rpgc has no job attributes for *JOBRUN
