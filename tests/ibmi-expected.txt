# Whether each test program should compile with IBM's ILE RPG compiler on a
# real IBM i — the "Should compile" column of the wiki page
# IBM-i-Conformance-Results (scripts/conformance-wiki.py).
#
# The default needs no entry here: a test registered in tests/run_tests.sh in
# "error" mode is written to be rejected, so IBM should reject it too; every
# other program should compile. This file lists only the exceptions, each with
# the reason it is one.
#
# Format:  <file>  compile|reject  <reason>

# rpgc refuses these on purpose — they are registered as error tests — but they
# are valid RPG, and IBM compiles them.
test159_fixed_ispec_err_zone.rpgle          compile  valid RPG; rpgc does not support I-spec record-identification zone codes
test177_fixed_cspec_err_call_dynamic.rpgle  compile  valid RPG; rpgc links calls statically, so it refuses a dynamic CALL
test195_fixed_cspec_err_move_declit.rpgle   compile  valid RPG; rpgc refuses MOVE of a decimal literal
test205_fixed_cspec_err_entry_f2.rpgle      compile  valid RPG; rpgc does not support Factor 2 on an *ENTRY PARM
test213_fixed_cspec_err_move_jobrun.rpgle   compile  valid RPG; rpgc has no job attributes for *JOBRUN
test226_err_subfield_inz.rpgle              compile  valid RPG; rpgc does not support INZ on a subfield

# Syntax-error tests, not registered through run_test.
test11_errors.rpgle            reject  syntax-error test
test11a_missing_semi.rpgle     reject  syntax-error test
test11b_bad_type.rpgle         reject  syntax-error test
test11c_unmatched_if.rpgle     reject  syntax-error test
test11d_bad_expr.rpgle         reject  syntax-error test
test11e_unmatched_paren.rpgle  reject  syntax-error test

# OpenRPG extensions: accepted by rpgc on purpose, rejected by IBM i.
test61_no_free.rpgle                 reject  OpenRPG extension: free-form without **FREE; IBM i requires the directive
test85_getenv.rpgle                  reject  OpenRPG extension: %GETENV has no IBM i equivalent (IBM: RNF0604, not a built-in)
